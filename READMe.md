## Playwright test automation framework with re-usable functions.

This framework can be re-use for any project/application under test.

Required dependencies installations:
> npm i
> npx playwright install 
> npm i dotenv

Environment variable dependencies:
> Add user credentials to .env (as: UserName and Password)

To run your tests in headed mode:
> npx playwright test --headed

Run the following command to generate a report: 
> npx playwright show-report
